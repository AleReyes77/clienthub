# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Security" tab → "Report a vulnerability").

Include the steps to reproduce, the affected endpoint or page, and the impact you expect.
You can expect a first answer within 7 days.

## Scope

ClientHub is a portfolio project. The security design and its known gaps are documented in
[docs/threat-model.md](docs/threat-model.md).
